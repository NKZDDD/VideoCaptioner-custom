客户任务模板（共享版 V38）

一、创建客户模板
1. 从左侧导航进入“客户模板”。
2. 点击“新建（读取当前设置）”，输入客户和用途名称。
3. 选择转录方式、音频语言、校正/翻译开关、字幕长度及显示方式。
4. 输入客户文字要求和专用词库，并选择外观模板。
5. 点击“保存到共享模板库”。其他电脑刷新列表后即可选择。

二、使用客户模板
任务创建页、批量处理页顶部均有客户模板下拉框。
选择模板即载入本机设置，再导入素材开始任务。
“自定义 / 使用当前设置”表示沿用当前控件数值，不恢复之前的旧设置。
任务开始时冻结客户参数和样式；之后切换客户不回写已开始的任务。
现有任务的 API 凭据仍属于运行设置，不随客户模板导出。

三、共享编辑与样式更新
客户模板使用版本检查，遇到其他人已修改的提示，应刷新后重编或复制成新模板。
不需要的模板可取消“启用”再保存，不会删除历史项目。
保存客户模板时冻结外观内容；原字体模板后续修改不会自动改变客户模板。
需要更新外观时，点击“重新读取外观模板”，再保存客户模板。
选择模板后临时调参不会自动覆盖共享模板。

四、边界
每集视频、台词剧本仍通过“剧本参考”页面绑定，不存入客户通用模板。
模板不包含 API Key、服务商地址、本地模型安装路径。
英文每条上限属于断句设置；每行上限属于显示换行。
极长旧字幕超过两行容量时沿用压缩宽度处理，保留全文。
视觉画布与剪映换算沿用所选择外观模板的已校准信息。

共享文件位置：AppData\customer_templates\<模板编号>.json。
工程记录保存当时的客户模板快照，方便排查与恢复。
所有电脑重启新版程序后即可看到入口。
